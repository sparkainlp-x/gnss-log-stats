# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities through a private GitHub Security Advisory for this repository rather than a public issue. Include a concise description and steps to reproduce using synthetic data only. Do not include real GNSS logs, coordinates, routes, or device identifiers.

There is no published response-time commitment. Please allow time for review before disclosing a report publicly.

## Data handling

The command-line program processes the supplied file locally and does not make network requests. GNSS logs and generated summaries may contain sensitive location information; protect them according to your own data-handling requirements. The repository does not accept real-world log samples as bug reports or fixtures.
